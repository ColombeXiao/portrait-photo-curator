# 专业人像审片与教学标准（必须参考）

## 1. 先评照片是否成立，不先上调色滤镜

按优先级查：
1. **视觉意图与决定性瞬间**：情绪是否自然、眼神或动作是否有意义；闭眼是不是刻意的情绪瞬间；多人照片中心人物/群体的关键表情。
2. **焦点与可用性**：主体的近眼是否合焦（若意图是剪影、动态或其他实验拍摄，可另评）；运动模糊和景深虚化必须区分；是否抖动、压缩糊与锐化涂抹。没有全尺寸图时不要根据联系表宣判 C。
3. **光**：主光方向、软硬、亮暗比例、面部鼻影与眼窝、眼神光；逆光人物与背景的亮度关系；高光和暗部是否仍保细节；避免混合色温导致皮肤不自然。
4. **构图和视觉重量**：主体、背景、前景层次；三分法只是工具，不强制居中/偏离；留白是否与视线及动作方向一致；头顶、关节、手足边缘是否被切；背景线条是否从头部穿出；地平线、垂直线及建筑透视。
5. **人物形态**：镜头太近造成的脸部透视拉伸、姿态与肢体交叠是否别扭、抓拍手势和人物/景物互动。
6. **色彩与表达**：肤色可信，背景和服装色彩关系明确，白平衡与场景氛围一致；避免为了统一色调消除夕阳暖色或冷夜景的故事性。
7. **技术完成度**：噪点、曝光余量、锐化过度、像素质量、噪点与纹理，拍摄设备信息只能在 EXIF 确切可读时提及。

## 2. 档位标准和边界情形

### A｜现在即可展示
- 技术达到在目标屏幕/社交平台直接展示的标准，人物情绪/构图/色彩表达完整；曝光不一定教科书式中性，风格偏暗、偏暖、颗粒可合理。
- 若小瑕疵不会改善作品主要观看体验，可归 A，提醒“维持现状”。
- 解释优势至少覆盖若干不同维度，最好讲述可复现的“光在哪里、人物与背景多远、手机/相机怎么站、如何引导表情”。

### B｜后期能显著改善
- 优秀拍摄瞬间存在，但需要合理裁切、修地平线/背景、曝光白平衡微调、局部压暗或轻度消除小干扰；严格检查裁剪后的可用像素和主体完整性。
- B 不代表必然要调曝光、磨皮、锐化；有时只需一步裁切。**每一修改都说明针对什么缺点**。
- 禁止用“AI 画面生成补全”的想象方案当作可修建议。若主眼完全失焦、脸部运动模糊严重且没有可用清晰信息，一般 C 而不是承诺“锐化救回来”。

### C｜关键缺陷难以恢复
- 清晰度/瞬间/结构受不可逆损伤，如无法补救的失焦、严重主体抖动、意外闭眼且破坏作品情绪、主体关键部位遮挡或画外、无法挽救的严重曝光剪裁。
- **必须在大预览/原图复核**；不要因白平衡、肤色、背景杂乱、噪点、普通照片不够惊艳就判 C。
- 连拍中存在更好的照片不自动意味着其他照片是 C。
- C 写入分类结果时仅保留 ID/grade，C 文件夹中只放原片，不写个片理由。

## 3. 多人合照、旅游环境肖像、手机人像

- 先确定主角和拍摄目标。多人合照关注主体群体的表情同步与遮挡，不因一位背景游客眨眼就一律 C；旅行环境人像保留重要地标时，不能用过紧裁切抹去环境故事。
- 对手机大光圈算法边缘涂抹和人像景深作出区分；远景不清晰可能是拍摄意图。
- 结合照片内容建议下次拍摄：在静止人物时可让近眼对焦，保持主体与背景分离；移动人物下快门应更快，不能只说“设置 ISO 100”。没有 EXIF，不假装知道拍摄焦距。

## 4. 照片评价的证据标准

**差的评论**：曝光不准，构图一般，调亮一些，套暖色滤镜。

**好的评论**：人物右侧外套与墙面亮度接近，轮廓不够分离；这是主体-背景分离与局部对比度问题；醒图【调节】优先压暗墙面高光/略提人物阴影（例如 +8 起试），回看头发边缘是否自然；下次让人物向左移动半步，利用深色门洞作背景并保留侧向柔光。

教原理不只是点术语，需解释“成因—视觉后果—正确处理—拍摄方法”。拍摄建议应针对照片现场能复现的选择。
